# Security Policy

## Supported Scope

This repository is documentation-first and primarily contains profile, portfolio, and static asset content.

Security concerns that are still relevant include:

- Malicious or misleading links.
- Accidental inclusion of secrets.
- Supply-chain risks in automation/tooling configuration.

## Reporting a Vulnerability

Please report potential vulnerabilities privately by:

1. Opening a private security advisory on GitHub (preferred), or
2. Contacting the maintainer directly and including:
   - A clear description of the issue.
   - Reproduction steps (if applicable).
   - Impact assessment.
   - Suggested mitigation (optional).

## Response Expectations

- **Acknowledgement target:** within 3 business days.
- **Triage target:** within 7 business days.
- **Remediation window:** depends on severity and complexity.

## Disclosure Policy

Please do not publicly disclose vulnerabilities until remediation is available and coordinated disclosure is approved.
